# Motion

Nothing eases. A committed change inverts the element for one beat; a card, a toast and the veil arrive in three steps; a cursor blinks in whole steps. Reduced motion swaps each for a still sign.

## Durations

::Tokens{prefix="--semantic-duration"}

## Arriving cards

A card steps up to full size from this scale.

::Tokens{prefix="--semantic-number-scale"}

## The invert flash

`Announcer.Flash` inverts an element for one beat of `--semantic-duration-flash`: the sign that a change was committed. Return it beside `Announcer.Announce`, which says what the flash shows. With reduced motion it holds a still ink ring for the beat instead.

::Example{name="flash"}

## The busy cursor

A busy control prints a cursor that blinks in whole steps of `--semantic-duration-blink`.

::Example{name="busy-cursor"}

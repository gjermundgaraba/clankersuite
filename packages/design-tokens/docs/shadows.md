# Shadows and layers

Only what floats over the page casts a shadow: a hairline ring and a soft drop falling straight down. An in-flow surface that must stand off the ground, such as the current place in a sidebar, takes only the ring (`hairline`), in place of a border, and lifts nothing. Controls sit flat.

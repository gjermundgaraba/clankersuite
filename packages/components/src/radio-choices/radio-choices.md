# Radio choices

A choice of one, each option a name and an optional note. A click anywhere on an option chooses it; the group is one stop for Tab, and the arrows move the selection. The chosen option's mark is a diamond, so a single choice reads apart from a checkbox.

The selection is the application's: the choices report `Selected` and the application keeps the value, passing it back as `selectedValue`. Put it in a `Fieldset` to name it on the page.

# Password field

A boxed password field with a show toggle inside its box. The toggle is a button named "Show password", pressed while the password prints in the clear. The application keeps whether it shows, as it keeps the value, and hides it again when the form is sent.

Give it `autocomplete`: `current-password` to sign in, `new-password` to set one.

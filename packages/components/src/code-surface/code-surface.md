# Code surface

Code to read: a head-tinted block in the system monospace. It wraps rather than scrolls. It takes focus, so a keyboard reader can reach it, and its label names it for screen readers: a file name, `"Response body"`. Its body is a string, or a highlighter's spans, whose `tok-*` classes take the content inks.

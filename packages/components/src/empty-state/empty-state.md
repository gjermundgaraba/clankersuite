# Empty state

What a panel says when it has nothing to show, centred where its content would be: what is missing, in pixel caps, one sentence on how it fills, and the button that fills it.

::Example{name="empty"}

## Heading level

`headingLevel` is required, because the two choices look alike and only the outline tells them apart. Give a heading level where the empty state is the main content of the page or a section: `3` inside a panel, whose title is an `h2`, as here; `1` for a gate or a missing page. Give `"Strong"` where it is not, such as a chart with no data.

# Textarea field

A labelled textarea with its help line, boxless like a `Field`, on a dotted baseline with an ink corner grip. It opens at `rows` lines and grows with its text from there.

::Example{name="notes"}

## Mono

Code and identifiers print in the system monospace. Further attributes go to the `<textarea>`: here a placeholder, with spelling and capitals off for host names.

::Example{name="hosts"}

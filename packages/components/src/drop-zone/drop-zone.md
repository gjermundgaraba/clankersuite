# Drop zone

A box to drop files on: dashed while it waits, solid and tinted while a file hovers it. Its button chooses files for those who cannot drag. It reports `ReceivedFiles`, or `RejectedNonFiles` for a drop that held no files (text, a link), which the application says through the live region.

Drop a file on it, or choose one: the word under the sentence says what the last drop did, and is taken back after a beat.

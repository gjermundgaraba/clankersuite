# Prose

Authored text at 15/1.65 sans within a 68ch measure; code and tables may run wider. It styles the plain elements it holds, so the view a Markdown renderer makes of a document needs no classes. This page's text is in one.

## Elements

Paragraphs, lists, block quotes, inline code and links, and headings at every level. `h1` prints as `h2`, a section under the page's own title; `h3` at the body's size; `h4` in pixel caps; `h5` in bold 13px type; `h6` as a muted pixel label, so no two neighbouring levels look alike.

::Example{name="elements"}

## Under a title

Inside a titled container, a Sheet's `h1` or a Dialog's `h2`, shift a document's headings so its top level sits under the container's title.

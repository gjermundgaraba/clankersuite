# Mark

The viewfinder glyph on amber: this one, among many, needs attention. It is an image named by its label, which the application's Tips shows as its tip.

## Marks

Where every row is marked, the mark prints plain: amber is for the one among many. With `onToggle` the mark is a toggle button that says whether it is pressed.
